# NPWD

A Who's-Who of characters. 

Users will be able to:
  - [ ] Enter Chanracters including their name and a description
  - [ ] Enter relationships between characters
  - [ ] View these character-character relationships on a filterable graph
  - [ ] Have multiple "universes" for different book series
  - [ ] Plot events on a timeline and link them to people


--- 

Character-relationship graph nodes should be generic nouns/nodes - we'll be able to place more than just
people on the graph.
